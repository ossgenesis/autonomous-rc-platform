# Security Policy

## Supported Versions

Currently, all active development is supported. If you find a bug or a vulnerability, please report it.

## Reporting a Vulnerability

Please do not open a public issue for security vulnerabilities. Instead, please email the maintainers directly. 

We will acknowledge receipt of your vulnerability report and strive to send you regular updates about our progress. If you report a vulnerability, we will work with you to understand the problem, resolve it, and coordinate disclosure.
